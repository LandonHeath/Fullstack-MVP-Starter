# Full-Stack MVP Starter

A boilerplate full-stack project with:

- React + Vite + Tailwind
- Node.js + Express
- Prisma + PostgreSQL

## 🧠 Learning Roadmap

### Month 1 – Frontend
- [ ] HTML/CSS refresh, responsive layouts
- [ ] JavaScript ES6+ and DOM
- [ ] React fundamentals (components, hooks, props)
- [ ] Tailwind CSS basics

### Month 2 – Backend + DB
- [ ] Node.js & Express routing
- [ ] REST API design (GET, POST, PUT, DELETE)
- [ ] PostgreSQL with Prisma
- [ ] Connect backend to frontend

### Month 3 – Full-Stack Apps
- [ ] User auth with JWT or Clerk.dev
- [ ] Protect routes/pages
- [ ] Host frontend (Vercel), backend + DB (Render)
- [ ] Polish MVP project + build another
